# Jiqiren Tap

## How do I install these formulae?

`brew install jiqiren/tap/<formula>`

Or `brew tap jiqiren/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jiqiren/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
